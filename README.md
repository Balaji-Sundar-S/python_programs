# 🐍 Python Interview Coding Practice

A structured collection of Python coding problems and solutions for improving problem-solving skills and preparing for software engineering interviews at **tier-1 product companies**.

The practice starts from Python fundamentals and gradually progresses toward common coding-interview patterns and LeetCode-style problems.

## 🎯 Goal

The main goal is to build strong programming fundamentals and problem-solving ability rather than simply memorizing solutions.

The progression is intentionally **slow and structured**:


## 📚 Practice Approach

Each problem is solved independently before moving to the next one.

For every problem:

1. Understand the problem
2. Think about the logic
3. Write the solution
4. Test with different inputs
5. Review the solution
6. Understand edge cases
7. Move to the next problem

The focus is on understanding **why the solution works**, not just getting the correct output.

## 🚀 Interview Preparation Philosophy

This repository is not intended to be a collection of copied solutions.

The objective is to develop the ability to:

* Understand an unfamiliar problem
* Break it into smaller steps
* Identify the appropriate pattern
* Write a solution from scratch
* Analyze edge cases
* Improve the solution when necessary
* Explain the approach clearly during an interview
* Understand time and space complexity

Optimization will be introduced gradually after the underlying logic is understood.

## 🎓 Target

Primary focus:

**Software Engineering / SDE interviews at tier-1 product companies**, including companies such as Atlassian.

The eventual goal is to become comfortable solving coding problems under interview conditions while maintaining a strong understanding of the underlying concepts.
